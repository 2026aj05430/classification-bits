# classification-bits
Implementing different machine learning classification algorithms
 Problem Statement
The objective of this project is to build, evaluate, and compare multiple supervised machine learning classification models on a multiclass dataset. By deploying an interactive dashboard using Streamlit, the system allows users to upload test data, automatically apply necessary preprocessing steps (such as feature scaling), generate predictions, and evaluate model performance across multiple standard classification metrics.
 Dataset DescriptionDataset Format: Semicolon-separated (.csv) file.Target Variable: Multiclass categorical label (e.g., stored under a column named Target or the final column).Features: Includes a mix of continuous and numerical variables representing input attributes.Train/Test Split: The dataset is pre-split or uploaded via a test dataset file (test_data.csv) containing $885$ samples.c.
